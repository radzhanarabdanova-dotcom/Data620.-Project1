# Project 1: Centrality in Zachary's Karate Club Network

Compares degree and eigenvector centrality across the two groups of the Karate Club network (34 nodes, 78 edges).

- Data: `networkx.karate_club_graph()` (Zachary, 1977)
- Methods: degree and eigenvector centrality, Welch's t-test, Mann-Whitney U test
- Notebook: `karate_club_centrality.ipynb`
- Requirements: networkx, pandas, matplotlib, seaborn, scipy
